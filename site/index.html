Zero-Trust Cloudflare Tunnels

Access storage globally without router port forwarding or exposing your IP. Automated dedicated subdomain routing with edge SSL certificates.

Universal Linux Support

Automated package manager integration for Debian, Ubuntu, Kali Linux, Arch, Fedora, openSUSE, and Alpine across both x86_64 and aarch64.

🐳

Hardened Rootless Docker

Operates strictly as unprivileged user mornye (UID: 1000) with cap_drop: ALL and protected loopback coexistence on port 8001.

Standard RFC 4918 WebDAV

Mount native network drives in Windows 11/10 Explorer, macOS Finder, GNOME Files, and stream directly via VLC or Symfonium media players.

Self-Healing System CLI
