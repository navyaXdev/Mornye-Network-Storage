Mornye Network Storage — Open-Source Linux WebDAV Server

A hardened, lightweight self-hosted network storage system and RFC 4918 WebDAV server for Linux, created and maintained by NavyaXdev. Engineered with rootless Docker, Argon2id encryption, and automated Cloudflare Zero-Trust Tunnels.

Get Started → Explore Guides View on GitHub →
$ curl -fsSL https://raw.githubusercontent.com/navyaXdev/Mornye-Network-Storage/main/setup.sh | bash
Project Identity & Distinction: Mornye Network Storage is an open-source Linux self-hosted network storage system and WebDAV server created and maintained by NavyaXdev. It is completely independent of the Flutter/Rust desktop music application (mornyeapp).

Engineered for Performance, Security & Control

Everything you need to replace proprietary cloud storage with your own sovereign private server.

🔒

Argon2id Authentication

OWASP-recommended cryptographic password hashing with 64 MB memory cost and 4 threads. High entropy secrets with zero hardcoded defaults.

☁

Zero-Trust Cloudflare Tunnels

Access your storage globally without opening firewall ports, forwarding router ports, or dealing with CGNAT. Automated dedicated subdomain routing.

🐧

Universal Linux Support

Tested and automated across Debian, Ubuntu, Kali Linux, Arch, Fedora, openSUSE, and Alpine on both x86_64 and aarch64 architectures.

🐳

Hardened Rootless Docker

Container operates strictly as unprivileged user mornye (UID: 1000) with cap_drop: ALL and loopback host port coexistence.

📁

Standard RFC 4918 WebDAV

Mount native network drives in Windows 11/10 Explorer, macOS Finder, GNOME Files, and stream directly via VLC or Symfonium audio player.

🩺

Self-Healing System CLI

Unified ./mornye.sh doctor --fix audits 11 system categories and automatically resolves permission issues, port conflicts, and config drift.
