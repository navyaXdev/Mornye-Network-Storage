PROJECT ARCHITECTURE & ORIGIN

Engineering Vision &
Open Source Sovereign Storage

Mornye Network Storage is an open-source, community-driven project engineered by NavyaXdev to give developers, homelab enthusiasts, and sysadmins complete ownership of their data without proprietary cloud subscription locks.

Core Engineering Tenets

Radical Simplicity

Zero bloat. No complex web apps, no heavy PHP interpreters, and no unnecessary tracking scripts. Just pure, RFC 4918-compliant WebDAV streaming natively into your operating system's file manager.

Uncompromising Security

Hardened rootless Docker containerization (UID 1000), OWASP Argon2id password hashing, binary MIME signature inspection, and zero open inbound router ports via Cloudflare Tunnels.

Operator Autonomy

Full control via a unified POSIX CLI (./mornye.sh). Zero-downtime hot SQLite database snapshots, automated self-healing repair mechanisms, and full uninstaller safety guarantees.

Distinct Project Identity

Mornye Network Storage is an open-source Linux self-hosted network storage system and RFC 4918 WebDAV server engineered and maintained by NavyaXdev. It is completely independent and separate from the desktop music player application named Mornye (mornyeapp) developed using Flutter and Rust. Mornye Network Storage focuses entirely on server-side private cloud storage infrastructure, rootless Docker containers, POSIX CLI system administration, and Cloudflare Zero-Trust WAN tunneling.
