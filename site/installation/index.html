Mornye Network Storage Installation Guide

Engineered by NavyaXdev • Version: v3.3.0 • Estimated Time: 2 Minutes

This guide covers installing and configuring Mornye Network Storage on modern Linux servers. Thanks to Mornye's universal package manager detection, installation is automated regardless of whether you run Debian, Ubuntu, Kali Linux, Arch Linux, Fedora, openSUSE, or Alpine Linux.

System Prerequisites

  • Operating System: Any modern Linux distribution (Kernel ≥ 5.10; verified up to Kernel 7.1.5+).
  • Architecture: x86_64 (amd64), aarch64 (ARM64), or armv7l.
  • Memory: Minimum 1 GB RAM (2 GB recommended).
  • Disk Space: Minimum 2 GB free disk space for the base container and database; additional disk space for file storage.
  • Privileges: Sudo or root access during initial package installation.

Method 1: One-Line Quick Installation (Recommended)

The fastest way to install Mornye is via the official curl installer:

curl -fsSL https://raw.githubusercontent.com/navyaXdev/Mornye-Network-Storage/main/setup.sh | bash

This command securely downloads the automated setup installer and launches the interactive configuration wizard.

Method 2: Git Clone & Guided Setup Wizard

If you prefer inspecting the source code before running, clone the repository directly:

# 1. Clone the official repository
git clone https://github.com/navyaXdev/Mornye-Network-Storage.git
cd Mornye-Network-Storage

# 2. Make scripts executable
chmod +x setup.sh mornye.sh

# 3. Launch the 6-stage setup wizard
./mornye.sh install

The 6-Stage Installation Wizard Explained

When you launch ./mornye.sh install (or setup.sh), the script guides you through six automated lifecycle stages:

  1. Stage 1: System & Hardware Audit: Checks CPU architecture, RAM, free disk space, and detects the distribution's native package manager (apt, pacman, dnf, zypper, or apk).
  2. Stage 2: Dependency Installation: Automatically provisions Docker Engine, the Docker Compose v2 plugin, curl, and cloudflared without user intervention.
  3. Stage 3: Storage Volume Initialization: Creates persistent storage directories (database/, storage/, logs/, backups/) and hardens ownership to UID:GID 1000:1000 with chmod 700.
  4. Stage 4: WebDAV Authentication Configuration: Allows you to enable Basic Authentication with a cryptographically secure generated password or your own custom password.
  5. Stage 5: Container Build & Deployment: Builds the production mornye-webdav image using multi-stage caching and starts the service in detached mode on protected port 8001.
  6. Stage 6: Network Ingress Selection: Choose between Local LAN mode, permanent Cloudflare Tunnel with dedicated subdomain routing, or ephemeral Quick Tunnels.

Post-Installation Verification

Once setup finishes, verify that your service is healthy and responding:

# Check system diagnostics
./mornye.sh doctor

# Probe WebDAV endpoint health
./mornye.sh health

# Test WebDAV authentication boundary
./mornye.sh webdav test
