DEPLOYMENT LIFECYCLE

Deploy in Seconds.
Run Sovereign Storage Anywhere.

Mornye features an intelligent, universal POSIX installer that detects your native package manager (APT, Pacman, DNF, Zypper, APK) and provisions rootless Docker, volumes, and ingress in under 2 minutes.

System Prerequisites

Operating System
Linux Kernel ≥ 5.10

Debian, Ubuntu, Kali, Arch, Fedora, openSUSE, Alpine (Tested up to Kernel 7.1.5+).

CPU Architectures
x86_64 / ARM64

Full multi-arch support for standard servers, VPS, Raspberry Pi 4/5, and SBC clusters.

RAM & Storage
1 GB RAM / 2 GB Free

Ultralight footprint. 2 GB disk for runtime binaries, container layers, and SQLite DB.

Security Boundary
Rootless Non-Root

Runs as unprivileged user UID 1000 with cap_drop: ALL and local loopback isolation.

Deployment Methods

METHOD 1 (RECOMMENDED)

One-Line Automated Curl Quickstart

FASTEST (~2 MIN)

Run this single command in your Linux terminal. The script downloads the official Mornye release, audits your hardware, auto-installs Docker and Cloudflare prerequisites, and launches the configuration wizard:

bash — automated-installer 
curl -fsSL https://raw.githubusercontent.com/navyaXdev/Mornye-Network-Storage/main/setup.sh | bash
METHOD 2

Git Clone & Guided CLI Wizard

INSPECT SOURCE

Ideal for system administrators who wish to inspect repository files and Docker configurations before execution:

bash — git-clone 
# 1. Clone the official repository
git clone https://github.com/navyaXdev/Mornye-Network-Storage.git
cd Mornye-Network-Storage

# 2. Grant executable permissions
chmod +x setup.sh mornye.sh

# 3. Launch the guided interactive wizard
./mornye.sh install

The 6-Stage Lifecycle Setup Wizard

When launched, Mornye executes a deterministic, self-healing sequence of automated setup stages:

STAGE 01 AUDIT

Hardware & System Audit

Inspects CPU architecture, available memory, disk space availability, and detects the distribution package manager without hardcoded assumptions.

STAGE 02 PROVISION

Universal Dependency Provisioning

Installs Docker Engine, Docker Compose v2, curl, and the official cloudflared binary using native distribution channels.

STAGE 03 HARDEN

Volume Initialization & Permissions

Initializes persistent storage directories (database/, storage/, logs/) and hardens ownership to UID:GID 1000:1000 with POSIX 700 permissions.

STAGE 04 CREDENTIALS

WebDAV Authentication Wizard

Configures credentials with cryptographically secure random password generation or custom passwords, hashed via OWASP-standard Argon2id.

STAGE 05 CONTAINER

Multi-Stage Container Build

Compiles the lightweight WebDAV production image, binds securely to host loopback port 8001, and drops all Linux capabilities.

STAGE 06 INGRESS

Network Ingress Selection

Select Local LAN mode, automated dedicated Cloudflare Subdomain (mornye.example.com), or ephemeral Quick Tunnels.

Post-Installation Verification

bash — health-check 
# 1. Run 11-category system diagnostics
./mornye.sh doctor

# 2. Probe WebDAV daemon health
./mornye.sh health

# 3. Test authenticated WebDAV response
./mornye.sh webdav test
