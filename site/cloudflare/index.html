ZERO-TRUST INGRESS

Zero Port Forwarding.
Encrypted Global Ingress.

Traditional self-hosted storage forces you to open ports on your router, configure dynamic DNS, and expose your residential IP. Mornye integrates native Cloudflare Zero-Trust Tunnels with automated dedicated subdomain provisioning.

Zero-Trust Ingress Flow

Instead of exposing your IP address or listening on inbound ports, the lightweight cloudflared daemon opens outbound, multiplexed QUIC/HTTP2 tunnels directly to Cloudflare edge data centers:

1. Permanent Domain with Automated Subdomain Integration

When you select Option 2 in Mornye's setup wizard, simply enter your root domain (e.g. example.com). Mornye handles all zone discovery and DNS record provisioning:

STEP 1: Root Domain Prompt

User supplies their apex domain: example.com or mydomain.in.

STEP 2: Automated Routing

Automatically maps and provisions: mornye.example.com.

STEP 3: Conflict Prevention

Validates DNS records and preserves unrelated CNAME/A records.

STEP 4: Edge SSL Provisioning

Cloudflare Edge instantly deploys HTTPS certificates across its global PoP network.

bash — tunnel-cli 
# Launch guided interactive tunnel configuration
./mornye.sh tunnel setup

# Or attach a root domain directly (auto-provisions mornye.yourdomain.com)
./mornye.sh tunnel domain add yourdomain.com

# Verify tunnel connectivity and latency
./mornye.sh tunnel status
./mornye.sh tunnel test

2. Ephemeral Quick Tunnels (Zero Registration)

Need to test remote WebDAV connectivity immediately without creating a Cloudflare account or registering a custom domain? Mornye generates ephemeral encrypted quick tunnels on demand:

bash — quick-tunnels 
# Start an ephemeral Quick Tunnel session
./mornye.sh tunnel quick start

# View assigned *.trycloudflare.com URL and tunnel uptime
./mornye.sh tunnel quick status

# Safely terminate the Quick Tunnel session
./mornye.sh tunnel quick stop
Quick Tunnel Ephemerality Note: Quick Tunnel URLs (ending in .trycloudflare.com) are temporary and regenerate on each restart. For permanent production access and mounting across desktop devices, configure a custom domain tunnel.

Cloudflare Edge Troubleshooting Reference

HTTP 502 Bad Gateway

The tunnel daemon is running but cannot connect to Mornye's container on port 8001.

Solution: Run ./mornye.sh doctor --fix
Error 1033 (Argo Tunnel Error)

Tunnel credentials or UUID mismatch between cloudflared and Cloudflare DNS.

Solution: Run ./mornye.sh tunnel domain reset
Error 524 (Timeout Occurred)

Upload of massive multi-gigabyte files exceeding standard HTTP edge timeouts.

Solution: Use chunked PUT or Map Network Drive
