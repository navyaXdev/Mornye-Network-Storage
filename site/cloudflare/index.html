Cloudflare Tunnel Integration & Ingress Guide

Engineered by NavyaXdev • Zero Port Forwarding • Automated Subdomains

Traditional self-hosting requires opening ports 80 and 443 in your home router, configuring dynamic DNS (DDNS), and exposing your public residential IP address to port scanners and DDoS attacks. Mornye Network Storage solves this by embedding native Cloudflare Zero-Trust Tunnel integration directly into the system lifecycle.

How It Works

Instead of listening for inbound connections through your firewall, the lightweight cloudflared daemon establishes an outbound, multiplexed QUIC/HTTP2 tunnel connection to the nearest Cloudflare Edge Point of Presence (PoP):

[Client Device] --- HTTPS TLS 1.3 ---> [Cloudflare Edge]
                                              |
                          Outbound Encrypted Tunnel (QUIC)
                                              v
[Linux Server]  <--- Loopback 8001 --- [cloudflared]

1. Permanent Custom Domain with Automatic Subdomain

When you provide your own domain managed through Cloudflare (e.g., mydomain.com), Mornye does not ask you to figure out complex DNS records. It automatically:

  1. Prompts for the root domain during setup: example.com.
  2. Generates the dedicated subdomain: mornye.example.com.
  3. Checks for existing DNS conflicts and provides clean override or coexistence.
  4. Provisions the CNAME record in your Cloudflare DNS zone automatically.
  5. Binds the tunnel service to route traffic to local port 8001.
# Guided tunnel setup wizard
./mornye.sh tunnel setup

# Or add your domain directly
./mornye.sh tunnel domain add example.com

# Verify live status and WAN connectivity
./mornye.sh tunnel status
./mornye.sh tunnel test

2. Ephemeral Quick Tunnels (Testing Without an Account)

Want to test remote connectivity immediately without connecting a Cloudflare account or registering a domain? Mornye includes full support for ephemeral Quick Tunnels:

# Start a temporary Quick Tunnel
./mornye.sh tunnel quick start

# Current temporary URL and uptime
./mornye.sh tunnel quick status

# Terminate session
./mornye.sh tunnel quick stop
Quick Tunnel Ephemerality:

Quick Tunnel URLs (ending in .trycloudflare.com) change every time the session restarts. For production daily use, configure a permanent custom domain tunnel.

Troubleshooting Common Cloudflare Errors

  • HTTP 502 Bad Gateway: Indicates the cloudflared daemon is running but cannot connect to Mornye on port 8001. Run ./mornye.sh doctor --fix to verify container state.
  • Error 1033 (Argo Tunnel error): The tunnel credentials or UUID mismatch. Run ./mornye.sh tunnel domain reset and re-authenticate.
  • Error 524 (A timeout occurred): Large file uploads exceeding edge timeouts. Use chunked uploads or the Map Network Drive client.
Detailed Tunnel Documentation:

Review in-depth technical specifications in the GitHub repository: docs/CLOUDFLARE_TUNNEL.md or follow the Installation Guide to configure tunnels during setup.
