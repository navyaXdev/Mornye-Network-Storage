Mornye Network Storage Features & Capabilities

Engineered by NavyaXdev • Version: v3.3.0 • License: MIT

Mornye Network Storage was architected to solve a specific problem: existing self-hosted cloud solutions (like Nextcloud or OwnCloud) are excessively heavy, requiring hundreds of PHP extensions, heavy databases, and bulky web frontends just to sync and stream files. Mornye provides a lightning-fast, POSIX-native RFC 4918 WebDAV server built on top of rootless Docker and modern cryptographic security.

1. RFC 4918 Compliant WebDAV Engine

WebDAV is the gold-standard protocol for native operating system integration without installing proprietary desktop sync clients:

  • Standard HTTP Methods: Full implementation of PROPFIND (directory listing and metadata queries), GET (streaming/downloading), PUT (streaming uploads), MKCOL (folder creation), MOVE (renaming/organizing), and DELETE.
  • Native OS File Manager Mounts: Map as a persistent network drive in Windows 11/10 Explorer, mount natively in macOS Finder via Cmd+K, or browse in Linux GNOME Files and KDE Dolphin.
  • Direct Media Streaming: Stream high-resolution FLAC, MP3, WAV, and AAC directly into media players such as VLC, Kodi, Infuse, and Symfonium without caching the whole library locally.

2. Enterprise-Grade Cryptographic Security

Security is not an afterthought in Mornye; every boundary enforces strict defense-in-depth principles:

  • OWASP-Recommended Argon2id Hashing: Passwords are protected using Argon2id key derivation with 64 MB memory cost, 3 iterations, and 4 parallel threads, providing resilient protection against GPU and ASIC cracking attacks.
  • MIME Header Binary Inspection: Every incoming upload is verified at the binary level using puremagic to inspect magic byte signatures, preventing disguised executables or malicious scripts from entering your storage.
  • Directory Traversal Shield: Path normalization rejects parent directory patterns (..), leading dots, and null byte injections.

3. Rootless Containerization & Port Protection

Container security is strictly enforced out of the box:

  • Non-Root Execution (UID 1000): The WebDAV service runs as unprivileged user mornye (UID: 1000, GID: 1000). The container drops all Linux capabilities (cap_drop: ALL) and prevents privilege escalation (no-new-privileges: true).
  • Loopback Isolation: The WebDAV engine listens strictly on 127.0.0.1:8001 on the host, preventing rogue exposure to external network interfaces.
  • Protected Coexistence: Mornye's host port 8001 isolates it from port 8000, allowing it to coexist peacefully alongside existing services (such as legacy streaming bridges or local web servers) without port collision errors.

4. Zero-Trust Cloudflare Ingress

Eliminate complicated router configurations and dangerous port-forwarding:

  • Automatic Dedicated Subdomain: Simply enter your root domain (e.g. example.com), and Mornye automatically creates and configures mornye.example.com with Cloudflare edge SSL.
  • Ephemeral Quick Tunnels: Need to test remote access instantly without a domain? Mornye spins up temporary, encrypted *.trycloudflare.com tunnels on demand.
  • Zero Router Port Forwarding: Works through strict firewalls and ISP Carrier-Grade NAT (CGNAT) by creating outbound encrypted QUIC/HTTP2 tunnels to Cloudflare edge nodes.

5. Self-Healing Diagnostics & CLI Telemetry

The unified POSIX Bash CLI (./mornye.sh) gives operators complete visibility and automated remediation:

  • 11-Category Health Audit: ./mornye.sh doctor examines Docker status, port occupancy, volume permissions, environment integrity, and tunnel connectivity.
  • Automated Auto-Repair: ./mornye.sh doctor --fix interactively diagnoses and repairs misconfigured permissions and configuration drifts with automated safety backups.
  • Hot SQLite Backups: Create consistent, hot database backups in online mode without taking the WebDAV server down.
