ENGINEERING CAPABILITIES

Architected for Speed.
Engineered for Sovereignty.

Traditional self-hosted storage suites are weighed down by bloated PHP interpreters, memory-hungry database engines, and slow web frontends. Mornye Network Storage replaces legacy weight with a hyper-optimized, RFC 4918 WebDAV engine, rootless container isolation, and Zero-Trust remote access.

PROTOCOL SPECIFICATION

1. Full RFC 4918 Compliant WebDAV Engine

WebDAV (Web Distributed Authoring and Versioning) is the gold standard for native operating system storage integration without proprietary desktop sync daemons. Mornye provides complete implementation of the official IETF RFC 4918 specification:

PROPFIND & PROPPATCH

Comprehensive XML property retrieval, directory recursion, and metadata synchronization across virtual collections.

GET & Byte-Range Streams

High-throughput file retrieval with HTTP 206 Partial Content support for seeking large media files (FLAC, MP4, MKV).

PUT & Atomic Writes

Streamed uploads written to temporary inodes before atomic rename, preventing partial or corrupted transfers.

MKCOL, MOVE, DELETE

POSIX filesystem compliance for folder hierarchy generation, instantaneous directory renaming, and recursive tree deletion.

Native OS Client Support: Maps natively in Windows 11/10 Explorer (Network Drive), macOS Finder (Cmd+K), Linux GNOME Files & KDE Dolphin, and streams directly into VLC, Kodi, Infuse, and Symfonium without third-party drivers.
DEFENSE-IN-DEPTH

2. Cryptographic Security & Payload Inspection

Every request entering Mornye passes through rigorous multi-layer validation before any byte touches your storage volumes:

OWASP Argon2id Hashing

Passwords hashed with Argon2id Key Derivation (64 MB memory cost, 3 iterations, 4 threads), providing maximum defense against GPU cracking clusters.

Binary Magic Byte Inspection

Incoming uploads undergo deep binary magic-byte inspection via puremagic to verify authenticity, preventing disguised executables or PHP scripts.

Path Traversal Defenses

Strict path normalization intercepts and rejects directory traversal exploits (..), null-byte injections (%00), and hidden system files.

Zero Plaintext Storage

Zero passwords or sensitive tokens are stored in plaintext. Credentials are systematically excluded from terminal logs, reports, and error traces.

CONTAINER HARDENING

3. Rootless Docker & Port 8001 Coexistence

Mornye is built from scratch around modern Linux container isolation best practices:

  • Non-Root Execution (UID 1000): The internal daemon executes exclusively as non-root user mornye (UID: 1000, GID: 1000). The container drops all Linux kernel capabilities (cap_drop: ALL) and activates no-new-privileges: true.
  • Loopback Host Isolation: The WebDAV service binds strictly to 127.0.0.1:8001 on the host loopback interface. Unauthenticated or raw traffic from the external network cannot bypass the ingress layer.
  • Zero Port Collisions: By utilizing host port 8001, Mornye coexists harmoniously alongside common services on port 8000 (such as Icecast streaming relays, development servers, or local dashboards) without port conflicts.
ZERO-TRUST INGRESS

4. Automated Cloudflare Dedicated Subdomain

Say goodbye to risky router port forwarding, static IP costs, and Carrier-Grade NAT (CGNAT) headaches:

Automated Subdomain Routing

Simply supply your root domain (e.g. example.com). Mornye's setup wizard automatically provisions and routes mornye.example.com via Cloudflare DNS APIs.

Zero Open Firewall Ports

Traffic flows via outbound-only encrypted QUIC / HTTP/2 tunnels to Cloudflare edge PoPs. Inbound ports on your router remain 100% closed.

Automatic Edge SSL & CDN

Enjoy global enterprise DDoS protection, automatic TLS 1.3 certificate renewals, and anycast DNS routing without managing Let's Encrypt renewal cron jobs.

OPERATIONAL RESILIENCE

5. Self-Healing Diagnostics & POSIX CLI

Mornye is built for headless server environments where zero downtime and immediate troubleshooting are mandatory:

  • 11-Category Health Engine: ./mornye.sh doctor verifies container liveness, port availability, disk space thresholds, volume write permissions, SQLite database integrity, and Cloudflare tunnel tunnel latency.
  • One-Click Interactive Auto-Repair: ./mornye.sh doctor --fix creates atomic safety backups of all configuration before interactively resolving permission drifts and broken socket links.
  • Online Hot SQLite Snapshots: ./mornye.sh backup performs zero-downtime database backups using SQLite's online backup API, ensuring complete database consistency without stopping WebDAV services.
