Key Enhancements in v3.3.0

AUTOMATED SUBDOMAINS

Supply root domain (example.com); Mornye automatically configures mornye.example.com via Cloudflare DNS.

ROOTLESS HARDENING

UID/GID 1000 execution with host port 8001 mapping to avoid collisions with port 8000 services.

AUTH SETUP WIZARD

Interactive credential wizard with cryptographically secure password generator and Argon2id hashing.

SELF-HEALING DOCTOR

11-category health engine with one-click interactive auto-repair via ./mornye.sh doctor --fix.
