What's New in v3.3.0

  • Automated Subdomain Routing: When providing a root domain (e.g. example.com), Mornye automatically provisions and binds mornye.example.com via Cloudflare.
  • Hardened Rootless Docker: Explicit UID/GID 1000 execution with host port 8001 mapping to prevent port 8000 collisions on host systems.
  • Interactive Auth Setup Wizard: Dedicated installation step allowing secure random password generation or custom password setup.
  • Self-Healing Diagnostics: 11-category system audit and one-click auto-repair via ./mornye.sh doctor --fix.
