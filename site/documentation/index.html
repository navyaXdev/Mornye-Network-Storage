Quick CLI Reference

# Check system diagnostics & auto-repair issues
./mornye.sh doctor --fix

# Start / stop / restart services
./mornye.sh start
./mornye.sh stop
./mornye.sh restart

# Check WebDAV endpoint health
./mornye.sh health
./mornye.sh webdav test

# Create hot online backup of SQLite database
./mornye.sh backup create
