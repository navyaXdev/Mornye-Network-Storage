CLI Command Cheatsheet

bash — mornye-cli 
# 1. Run 11-category health check & auto-repair issues
./mornye.sh doctor --fix

# 2. Lifecycle control: start, stop, restart services
./mornye.sh start
./mornye.sh stop
./mornye.sh restart

# 3. Test WebDAV endpoint and authentication boundary
./mornye.sh health
./mornye.sh webdav test

# 4. Create online hot backup of SQLite database
./mornye.sh backup create
