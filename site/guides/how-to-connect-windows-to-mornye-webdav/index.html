How to Connect Windows 11 & 10
to Mornye WebDAV Server

Author: NavyaXdev • Platform: Windows 11 / 10 Explorer • Read Time: 8 min

One of the chief advantages of Mornye Network Storage is that it adheres strictly to the RFC 4918 WebDAV standard. This means you do not need to install proprietary desktop synchronization clients that consume system RAM, run background telemetry, or slow down your operating system. Windows 11 and Windows 10 have native, built-in support for WebDAV via Windows File Explorer.

However, because the default Windows WebClient service was architected decades ago, Windows enforces two legacy constraints out of the box: a 50 MB maximum file transfer limit (Error 0x800700DF) and strict restrictions on Basic Authentication over unencrypted connections. In this guide, you will learn how to map Mornye as a permanent drive letter (e.g. Z:) and apply standard registry fixes to unlock full 4 GB+ transfers.

Step 1: Start the Windows WebClient Service

Windows File Explorer relies on the background WebClient service to communicate with WebDAV endpoints. Run PowerShell as Administrator:

powershell — start-webclient 
Set-Service -Name WebClient -StartupType Automatic
Start-Service -Name WebClient

Step 2: Fix the Windows 50 MB File Size Limitation

Error 0x800700DF:

"The file size exceeds the limit allowed and cannot be saved." This occurs when copying files larger than 50 MB due to an ancient Windows WebClient safety buffer.

To increase the file transfer limit to 4 GB (maximum allowed by the 32-bit DWORD registry key), execute this one-liner in PowerShell (Run as Administrator):

powershell — registry-fix 
Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\WebClient\Parameters" -Name "FileSizeLimitInBytes" -Value 0xffffffff -Type DWord
Restart-Service -Name WebClient

Step 3: Map Mornye as a Drive in File Explorer

  1. Open File Explorer (Win + E) and navigate to This PC.
  2. On the top ribbon menu, click the … (More options) menu and select Map network drive.
  3. Choose a drive letter (e.g., Z: or M:).
  4. In the Folder input, enter your Mornye WebDAV endpoint:
    https://mornye.yourdomain.com/dav/
    (Always include the trailing slash /)
  5. Check both:
    • ✓ Reconnect at sign-in
    • ✓ Connect using different credentials
  6. Click Finish, enter your Mornye username and password, check Remember my credentials, and click OK.

Alternative: One-Line Command via `net use`

cmd — net-use 
net use Z: https://mornye.yourdomain.com/dav/ /persistent:yes /user:admin YourPassword

Troubleshooting Common Windows Issues

Repeated Auth Prompts

Windows blocks Basic Auth over unencrypted HTTP. When using Cloudflare Tunnels with HTTPS (TLS 1.3), authentication works seamlessly.

Slow Directory Browsing

Open Internet Options (inetcpl.cpl) → Connections → LAN Settings → uncheck "Automatically detect settings" to disable slow WPAD proxy checks.
