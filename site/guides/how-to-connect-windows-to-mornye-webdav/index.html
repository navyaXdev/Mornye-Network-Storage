How to Connect Windows 11 & 10 to Mornye WebDAV

Author: NavyaXdev • Client Platform: Windows 11 / 10 Explorer • Read Time: 8 min

One of the chief advantages of Mornye Network Storage is that it adheres strictly to the RFC 4918 WebDAV standard. This means you do not need to install proprietary desktop synchronization clients that consume system RAM, run unnecessary background telemetry, or slow down your operating system. Windows 11 and Windows 10 have native, built-in support for WebDAV via Windows File Explorer.

However, because the default Windows WebClient service was architected decades ago, Windows enforces two legacy constraints out of the box: a 50 MB maximum file transfer limit (Error 0x800700DF) and strict restrictions on HTTP Basic Authentication over unencrypted connections. In this guide, you will learn how to map Mornye as a permanent drive letter (e.g. Z:) and apply standard registry fixes to unlock full 4 GB+ transfers.

Prerequisites

  • A running Mornye instance accessible via Cloudflare HTTPS (e.g., https://mornye.yourdomain.com/dav/) or LAN (http://192.168.0.x:8001/dav/).
  • Your configured Mornye WebDAV username and password.
  • Administrative privileges on your Windows PC (to adjust the WebClient file size limit).

Step 1: Ensure the Windows WebClient Service is Running

Windows Explorer relies on the background WebClient service to communicate with WebDAV servers. Ensure it is started and configured to launch automatically:

  1. Press Win + R, type services.msc, and hit Enter.
  2. Scroll down to find WebClient.
  3. Right-click WebClient → Properties.
  4. Set Startup type to Automatic, click Start, then click OK.

Alternatively, open PowerShell as Administrator and run:

Set-Service -Name WebClient -StartupType Automatic
Start-Service -Name WebClient

Step 2: Fix the Windows 50 MB File Size Limitation

By default, Windows WebClient limits any single WebDAV file transfer to approximately 50 MB (50,000,000 bytes). If you attempt to copy high-resolution FLAC audio tracks, 4K videos, or backup archives larger than 50 MB, Windows displays:

Error 0x800700DF:

The file size exceeds the limit allowed and cannot be saved.

To increase the transfer limit to the maximum 4 GB (4,294,967,295 bytes), modify the registry parameter FileSizeLimitInBytes:

  1. Press Win + R, type regedit, and hit Enter.
  2. Navigate to the following key: 
    HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Services\WebClient\Parameters
  3. Double-click FileSizeLimitInBytes.
  4. Select Decimal and change the value from 50000000 to 4294967295 (or ffffffff in Hexadecimal).
  5. Click OK.
  6. Restart the WebClient service via PowerShell: 
    Restart-Service -Name WebClient

One-Line PowerShell Fix (Run as Administrator):

Set-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Services\WebClient\Parameters" -Name "FileSizeLimitInBytes" -Value 0xffffffff -Type DWord
Restart-Service -Name WebClient

Step 3: Map Mornye as a Permanent Network Drive

Now map your Mornye storage server directly in Windows Explorer:

  1. Open File Explorer (Win + E).
  2. Click This PC on the left sidebar.
  3. On the top ribbon menu, click the … (More options) menu and select Map network drive (or press Alt + V, N).
  4. Select a drive letter (e.g. M: or Z:).
  5. In the Folder field, enter your Mornye WebDAV endpoint: 
    https://mornye.yourdomain.com/dav/
    (Make sure to include the trailing slash /)
  6. Check both:
    • ✓ Reconnect at sign-in
    • ✓ Connect using different credentials
  7. Click Finish.
  8. When the Windows Security prompt appears, enter your Mornye WebDAV username and password, check Remember my credentials, and click OK.

Windows Explorer will open your new drive letter immediately! You can now drag and drop files, create folders, stream music directly in VLC or foobar2000, and organize documents just like any local hard drive.

Alternative: Command Line Mapping via `net use`

You can also map Mornye from the command line or within automated startup scripts using net use:

net use Z: https://mornye.yourdomain.com/dav/ /persistent:yes /user:admin YourSecurePassword

Troubleshooting Common Windows WebDAV Issues

  • Credential Prompt Keeps Repeating: Ensure you are using HTTPS. Windows blocks basic authentication over unencrypted HTTP unless BasicAuthLevel is set to 2 in the registry. Cloudflare Tunnels provide HTTPS out of the box.
  • "The network path was not found": Ensure the WebClient service is running and verify that the URL ends with /dav/.
  • Slow Directory Browsing: In Windows Internet Options (inetcpl.cpl), go to Connections → LAN settings → uncheck Automatically detect settings. This prevents Windows from attempting WPAD proxy autodiscovery on every WebDAV query.
Seamless Native Integration:

Your Mornye storage is now mapped to Windows Explorer. Every file write is securely hashed with SHA-256 and stored on your sovereign Linux server.
