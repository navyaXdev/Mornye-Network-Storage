ZERO-TRUST NETWORKING

How to Configure Cloudflare
Tunnel Subdomains for Mornye

Author: NavyaXdev • Network Ingress: Cloudflare Zero-Trust • Read Time: 9 min

Self-hosting storage on home or office servers traditionally presents severe networking hurdles. Most consumer and small-business ISPs place connections behind Carrier-Grade NAT (CGNAT), share dynamic IP addresses, and aggressively block inbound traffic on ports 80, 443, and 8080. Opening ports in home routers also introduces significant security risks by exposing the server's public IP to internet-wide botnets and port scanners.

Mornye Network Storage overcomes these obstacles by integrating Cloudflare Zero-Trust Tunnels directly into its setup lifecycle. When configuring your custom domain, Mornye automatically creates a dedicated subdomain (mornye.<root-domain>), configures edge TLS 1.3 encryption, and establishes an encrypted outbound tunnel directly to Cloudflare's edge network—requiring zero open router ports.

The Automated Subdomain Architecture

STEP 01

Apex Domain Input

User supplies root domain: example.com or mydomain.in.

STEP 02

Subdomain Construction

Mornye automatically generates and routes: mornye.example.com.

STEP 03

DNS Zone Verification

Validates that the domain is active in your Cloudflare account without asking for zone IDs.

STEP 04

Outbound QUIC Tunnel

Establishes encrypted outbound tunnels from cloudflared to Cloudflare PoPs, routing to 127.0.0.1:8001.

Step 1: Authenticate Cloudflared CLI

bash — cloudflared-login 
cloudflared tunnel login

Step 2: Launch Guided Subdomain Wizard

Run the interactive tunnel setup script or add your domain non-interactively in one line:

bash — mornye-tunnel 
# Interactive Guided Setup
./mornye.sh tunnel setup

# Or attach your domain directly (auto-provisions mornye.example.com)
./mornye.sh tunnel domain add example.com

Step 3: Test WAN Ingress & Auth Boundaries

bash — probe-wan 
./mornye.sh tunnel test

Cloudflare Ingress Troubleshooting Matrix

Error Code / Status Underlying Cause Remediation Step
HTTP 502 Bad Gateway cloudflared is running, but Mornye container on port 8001 is unreachable. Run ./mornye.sh doctor --fix to verify container health.
Error 1033 (Argo Tunnel) Cloudflare edge cannot locate active tunnel daemon for this UUID. Restart tunnel with ./mornye.sh restart.
Error 1016 (Origin DNS) DNS CNAME record points to a deleted or non-existent tunnel UUID. Run ./mornye.sh tunnel domain reset and re-run setup.
HTTP 401 Unauthorized Expected behavior without credentials. Valid Basic Auth credentials required. Enter configured Mornye WebDAV credentials in client.
