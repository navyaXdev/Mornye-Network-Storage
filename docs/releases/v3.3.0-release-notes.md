## Highlights

Mornye Network Storage v3.3.0 introduces automated dedicated Cloudflare custom subdomain provisioning, RFC 1123 domain normalization, safe uninstaller tunnel cleanup, and persistent WAN configuration across system reboots.

### 1. Automatic Dedicated Cloudflare Subdomain (`mornye.<domain>`)
When operators configure custom domain WAN access via `./mornye.sh tunnel domain add` or Stage 5 of `./setup.sh`:
- You only need to enter your **root domain** (e.g., `example.com`, `mydomain.in`, `navya.dev`).
- Mornye automatically generates and routes the dedicated subdomain: **`mornye.<root-domain>`**.
- Includes **anti-recursion protection**: entering `mornye.example.com` automatically extracts `example.com` to prevent nested subdomains (`mornye.mornye...`).
- Strictly rejects invalid inputs (IP addresses, `localhost`, single labels, invalid TLDs).

### 2. DNS Conflict Resolution & Zero-Trust Safety
- Queries existing Cloudflare zone records; if a record for `mornye.<root-domain>` points elsewhere or has conflicts, Mornye safely updates it using `cloudflared tunnel route dns --overwrite-dns`.
- Ingress strictly maps to the internal WebDAV container (`http://webdav:8000`) on an isolated Docker network.
- Unrelated host services (such as SONG Bridge on port 8000 or host tunnels on port 20241) remain 100% untouched.

### 3. Lifecycle Persistence
- Configured root domain and generated subdomain are saved to `config/tunnel_info.env` and `.env`.
- On system restart or `./mornye.sh start`, Mornye re-establishes the tunnel and displays the public URL without asking the operator again.
- Added `./mornye.sh tunnel domain reset` to decouple routing and revert ingress to the default 404 catch-all.

### 4. Uninstaller Cloudflare Cleanup Menu
- `delete.sh` features an interactive 3-option Cloudflare cleanup menu:
  1. **Keep Cloudflare Tunnel**: Remove local storage but preserve remote tunnels and DNS records.
  2. **Remove Mornye Tunnel**: Verify UUID and ownership before deleting the Mornye tunnel and its DNS record, while preserving origin `cert.pem` and foreign services.
  3. **Cancel Uninstall**.

## Upgrade Instructions

```bash
cd Mornye-Network-Storage
git pull origin main
./mornye.sh restart
```

To configure an automatic dedicated subdomain on an existing installation:
```bash
./mornye.sh tunnel domain add example.com
```
